# ComfyUI-MediaBrowser

为 ComfyUI 的现有加载节点提供带缩略图的媒体浏览器，并带常驻浮钮入口。

无需新增节点或修改工作流。安装后会出现可拖动的猫耳头像浮钮，可直接浏览 `input`、`output` 与 `temp`。支持的加载节点上仍有“浏览资源”按钮，用来把文件填进该节点。

## 主要功能

- 文件夹浏览、递归检索、文件名搜索、类型筛选与多种排序方式
- 瀑布流与宫格布局，缩略图清晰度可按格子大小独立配置
- 图片、视频与音频预览；图片和视频支持大图翻页
- 收藏、最近使用和常用目录固定入口
- 多选、批量收藏与批量移入系统回收站
- 读取 PNG 或视频中的提示词、参数、工作流与生成耗时
- 可选的本地预览遮蔽，不修改原始文件
- 按当前画面复制图片，可选择是否携带工作流；智能与手动打码共用可编辑遮蔽层
- 桌面端、触屏与可缩放窗口布局
- 可拖动的常驻浮钮；可同时打开多扇浏览窗对照不同目录
- 中文、英文界面，可跟随 ComfyUI 语言

## 安装

### ComfyUI Manager

市场发布准备中，请先使用下方的手动安装方式。

### 手动安装

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/xinsulab/ComfyUI-MediaBrowser
```

克隆完成后重启 ComfyUI，无需额外配置。

## 使用

1. 点左下角可拖动的猫耳头像浮钮打开浏览窗。再点一次会再开一扇，方便对照两个目录。默认最多 5 扇。
2. 要选进加载节点时，仍在该节点上点“浏览资源”，点绿色勾或预览里的“用这张”。浮钮打开的窗口是纯浏览，不会改节点。
3. 使用目录下拉框切换 `input`、`output` 或 `temp`；“收藏”和“最近”位于目录旁边。切目录不会另开窗口。
4. 点击媒体打开预览。也可在设置中改为单击直接选中（只对节点选片窗有效）。
5. 右键媒体（触屏长按）可使用收藏、截图、复制纯图、提示词、工作流、遮蔽和回收站等操作。大图底栏支持框选与笔刷编辑；保存的是独立遮蔽层，不修改原文件。

列表、缩略图和预览由 ComfyUI 后端提供。服务停掉时浮钮还在，但扫盘会失败并提示服务不可用。

收藏和最近使用按真实目录分别保存。例如当前目录是 `output`，打开收藏时显示的是 `output` 中收藏的文件。

从 `output` 或 `temp` 选择文件时，插件会自动添加 ComfyUI 所需的目录标记。

## 支持的节点

插件会自动识别使用 ComfyUI 标准 `image_upload`、`video_upload` 或 `audio_upload` 控件的节点，同时显式适配以下常见节点：

| 节点 | 支持内容 |
|---|---|
| `LoadImage`、`LoadImageMask` | `input` 图片 |
| `LoadImageOutput` | `output` 图片 |
| `VHS_LoadVideo`、`VHS_LoadVideoFFmpeg`、`LoadVideoAndSegment_` | `input` 视频 |
| `VHS_LoadAudioUpload` | `input` 音频 |
| Crystools 带元数据图片加载节点 | `input` 图片 |
| `LoadImageGoohai`、`LoadImage //Inspire` | `input` 图片 |

编辑工具使用独立浮窗，自动比较图片周围的空白，优先靠右并尽量避开图片，不挤占图片显示空间。空间足够时展开全部操作，窄屏或低屏才收进「更多」。拖动工具条的把手可自由摆放（支持鼠标和触屏），位置在本次查看期间保留；「更多 → 恢复自动位置」可恢复自适应摆放。主面板右上角的「浏览器全屏」可隐藏浏览器顶部，进入后短暂显示退出按钮。鼠标移到顶部中央、触屏轻点顶部中央可再次显示；键盘也可按 Esc 退出。浏览器不支持全屏时会提示。

## 可选：预览遮蔽

「显示遮蔽」控制区域遮蔽层的显示，取消勾选不会删除记录。「整图模糊」独立控制整张图片的遮蔽。

- 点击智能打码或手动编辑会自动开启遮蔽，无需预先切换模式。
- 手动编辑默认接着已有结果修改，支持矩形移动/缩放、删除选区、笔刷、撤销/重做和清空；点击画笔直接涂抹，工具面板自动摆放；完成保存图层，右上角 × 关闭工具，有未保存修改时可选择保存、放弃或继续编辑。「放弃本次修改」恢复进入前的状态。编辑中滚轮可缩放，按住空格加左键或用中键拖动可平移，点击图片不会关闭；普通左键仍用于绘制。编辑时仍使用底栏的「复制图片」与「复制图片及工作流」两个按钮；本轮智能识别支持一步撤销。
- 编辑遮蔽时可切换「模糊 / 马赛克」，对应调整「强度 / 色块」。新画区域默认模糊；选中区域后只修改该区域，无选区时切换全部区域的效果，滑块调整同类效果。自动识别区域也可修改，切换与调整均支持撤销。
- 主动点击智能打码会保留手工修改，并允许恢复已删除的自动框；后台检测仍尊重删除记录。原文件被替换时不会套用旧遮蔽。
- 复制和截图使用当前显示状态，编辑期间使用当前草稿。两种复制的图片像素一致；「含工作流」还同时复制工作流 JSON 文本。部分接收软件会清理图片元数据，不能保证 PNG 内嵌信息在任意软件之间传递。
- 遮蔽记录保存在插件的 `_overlays/` 目录中，重启后仍可继续编辑；备份或迁移时请保留该目录。

启用智能打码需要：

1. 在浏览器设置中下载推荐 ONNX 模型，或选择兼容的模型文件。
2. 在 ComfyUI 使用的 Python 环境中安装 `onnxruntime`。

模型保存在插件的 `_models/` 目录，不包含在仓库中。无需安装 `nudenet` 或 `ultralytics`。

## 数据与安全

- 收藏、最近使用、界面偏好和单图标记保存在浏览器本地存储中。
- 缩略图和检测结果使用插件本地缓存；源文件变化后缓存会自动失效。
- 删除操作只移入系统回收站，并在执行前确认。
- 预览、提示词读取和耗时索引不会修改原始媒体文件。智能与手动打码仅保存遮蔽记录，不覆盖原图。旧版已经写入原图的马赛克无法还原。

## 已知限制

- 视频封面需要 VideoHelperSuite、`imageio-ffmpeg` 或系统 PATH 中可用的 ffmpeg。没有 ffmpeg 时仍可选择和播放视频。
- 部分浏览器不支持 AV1、HEVC 等视频编码；文件本身不受影响。
- 音频不生成缩略图封面。
- JPG 与 WebP 通常不包含 ComfyUI 工作流或完整生成参数。
- 局部检测仅支持插件推荐的检测模型系列，其他结构的 ONNX 文件不能仅通过修改路径直接使用。
